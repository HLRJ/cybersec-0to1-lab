# 实验规则

本课程的第一条规则不是“会不会打”，而是“有没有权测”。

## 允许的目标

只有以下目标可以进入课程实验：

1. 本仓库明确提供的靶场；
2. 你自己拥有、并明确用于实验的主机或虚拟机；
3. 获得明确授权、且测试范围写清楚的目标。

## 默认拒绝

如果目标来源不清楚、范围不清楚、授权不清楚，默认拒绝。

课程中的主动探测脚本应优先采用 allowlist，而不是“只要不是公网就都允许”。

## 本课程默认实验网

当前 starter 默认允许：

- `127.0.0.0/8`：本机回环地址；
- `192.168.77.0/24`：计划用于 VMware Host-Only 的实验网段。

修改范围前先预测影响，再运行测试验证。
