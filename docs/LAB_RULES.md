# 实验规则

本课程的第一条规则不是“会不会打”，而是“有没有权测”。

## 允许的目标

只有以下目标可以进入课程实验：

1. 本仓库明确提供的靶场；
2. 你自己拥有、并明确用于实验的主机或虚拟机；
3. 获得明确授权、且测试范围写清楚的目标。

## 默认拒绝

如果目标来源不清楚、范围不清楚、授权不清楚，默认拒绝。

课程中的主动探测脚本应优先采用 allowlist，而不是“只要不是公网就都允许”。

## 先有资产，再定义 Scope

S00-L01 先创建真实的 Host-Only Cyber Range；S00-L02 再把**实际创建出来的实验资产**写进 Scope。

仓库当前提供一套参考实现：

- `127.0.0.0/8`：本机回环地址；
- `192.168.77.0/24`：课程开发时使用的 VMware Host-Only 参考网段。

`192.168.77.0/24` 不是要求所有学习者照抄的“默认授权私网”。如果你的专用 Host-Only 网络使用其他不冲突的网段，应把 `scope/lab-scope.yaml` 改成你自己的真实实验网段，并运行测试验证。

**私网地址 ≠ 已授权地址。** 家庭 WLAN、公司内网、生产网以及其他能访问的 RFC1918 地址，不会因为“不是公网”就自动属于课程 Scope。

修改范围前先预测影响，再运行测试验证。
